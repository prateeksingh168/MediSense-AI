
# 🩺 MediSense AI

> AI-Powered Healthcare Support & Clinical Decision Support System

## 📌 About the Project

MediSense AI is an intelligent healthcare support system designed to assist **patients** and **doctors** through AI-powered symptom analysis, health tracking, safety alerts, and explainable clinical decision support.

**⚠️ AI assists. Doctors decide.**

---

## 🎯 Project Objective

To build a smart healthcare platform that helps:

- Patients monitor symptoms and receive safety alerts.
- Doctors prioritize patient cases using AI-powered insights.
- Improve decision-making through explainable AI, not replace medical professionals.

---

## 👥 User Roles

### 👤 Patient

- Register & Login
- Enter Symptoms
- Track Health History
- Receive AI Safety Alerts
- View Previous Assessments

### 👨‍⚕️ Doctor

- View Patient Cases
- Priority-based Dashboard
- AI Probable Condition
- AI Explanation
- Accept / Override AI Recommendation

## ✨ Core Features
